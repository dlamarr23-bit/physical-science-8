review-game v2026.11.03b

- Each question now fills the whole screen on Chromebooks, laptops and phones: a bigger picture, bigger question text and bigger answer tiles,
  with nothing to scroll on a Chromebook. A long question or long answers shrink just enough to fit. On a phone the answers go 2 by 2
  (or one under another when they are long), the page scrolls, and the power-ups stay at the bottom of the screen.
- Two new power-ups: 50/50 takes away two wrong answers (not on two-answer or select-all questions), and Second guess gives one more try
  after a wrong answer (only the second answer counts, and a right one earns its points). Power-ups still come every 4 answers, now from five kinds.
- The Correct / Incorrect bar now sits where the power-ups were, so it never covers the answers.
- Fix: a game that sent its points before the class website kept game titles showed on the website Leaderboard under All topics only,
  not under its own topic. The sheet now sends its title (with every student's points) at its next hourly check, and again whenever you
  change the Assignment title. Self-Check > Send game points to the website leaderboard now does the same right away.
- Students who open the game through the class website (Class Pass) get the new screen as soon as it is published. Students who open the
  sheet's own link (school Chromebooks usually go there) get it after you paste the new Index, so paste both files.
- Your questions, settings, scores and leaderboard are not touched.

Also from 2026.10.30c (optional), if this sheet skipped it:
- Paste safety: this sheet remembers what kind of assignment it is (from the first time you run Self-Check > Set up / repair sheets with this code).
  If code for a different kind is ever pasted in, the Self-Check menu shows only a warning (for example "This sheet is a Review Game, but this code is for a Self-Check (one column). Undo the paste."),
  and Set up, grade uploads and the student page stop until you undo the paste. To change a sheet's kind on purpose, use the menu's "Make this sheet ..." item.
- Check for skill updates shows which kind of sheet the code is for, in large text, so you can see you're copying the right code.
- Your Assignment Launchpad card says "Wrong code pasted" if that ever happens.

Also from 2026.10.30b, if this sheet skipped it:
- Check for skill updates now also finds new versions on the class website, so an update reaches this sheet as soon as it is published, with no files needed in the Drive folder. Your Drive folder Claude Skill Updates still works too, and the update window says where each version came from.
- The copy on the website has no questions or answer keys (the website is public). Your questions live in your Questions tab, so nothing changes for you. If a sheet's Questions tab were ever empty, the window would tell you to run Self-Check > Set up / repair sheets first.
- Your questions, answer keys, settings and student work are not touched.

Also from 2026.10.30 (the review game's first release), if this sheet skipped it:
- Right or wrong shows the moment a student picks an answer, and the sheet saves in the background. (If your game already does this, nothing changes for students.)
- Faster opening when a whole class starts the game at once.
- Your Assignment Launchpad card shows the game's Auto grade and Full credit at settings.
- Your questions, settings, scores and leaderboard are not touched.

After you paste the new Code.gs and Index and create the New version (Deploy > Manage deployments > pencil > New version > Deploy), run Self-Check > Set up / repair sheets once.
That is when the sheet remembers its kind; it also adds any Settings rows the sheet doesn't have yet. Nothing already in the sheet changes, and no new permission is needed.
