review-game v2026.11.11c

- Faster pictures for a whole class. A big picture now travels as a smaller copy that Google Drive makes (1600 pixels wide, what the page
  shows anyway), so a 5 MB photo is sent as about 200 KB. The size of the file in Drive no longer matters: there is no 8 MB limit any more
  (only a picture Drive can't make a smaller copy of still has it). Small pictures and GIFs are sent as they are.
- The sheet keeps each picture ready for 6 hours (it was 1 hour), and the hourly check puts back any that dropped out, so students get the
  kept copy and the sheet doesn't read Drive again for every class.
- Changed a picture file in Drive but kept the same link? Run Self-Check > Check the Questions tab for problems (or Set up / repair sheets):
  it reads every picture again right away. A new link shows up by itself.
- Chromebooks open faster. The first time, the student link checks out of sight that Google knows the student, then opens the assignment.
  After that, the same Chromebook skips the check for 30 days and goes straight to the assignment: one trip to the sheet instead of two, so a
  class of 36 opening together makes half as many trips. If the same Chromebook is back at the link within 10 minutes, the check runs again.
- If Google Drive turns a picture away on the sheet's own link (it can when a whole class asks for the same pictures at once), the picture
  now comes through the sheet instead of staying blank.
- The game page still loads a question's pictures when that question comes up; each one now arrives smaller and from the kept copy.
- To use it: Update now on the Launchpad, or paste the new Code.gs and Index and make a New version. No Set up / repair needed (no new
  Settings rows or columns) and no new permission.
- The class website's pages work with a sheet that hasn't been updated yet (pictures then come one at a time, as before).
- Your questions, answer keys, settings and student work are not touched.

  so you can upload (or upload and return) one class's grades at a time. 3b still asks first, and names the class. The Grade Uploads tab

- Unticking a class that already has the assignment leaves it in Classroom; tick the class again and the sheet finds the same assignment.
- Start a new school year also clears the Classes tab (step 1 lists this year's classes again).
- To use it: Update now on the Launchpad, or paste the new Code.gs and Index and make a New version. Then reload the sheet to see the
  new menu. No Set up / repair needed. The first time you run step 1, the Classes tab shows the classes already linked, ticked.

Also from 2026.11.10 (optional), if this sheet skipped it:
- New Settings row "Questions per try" (right after "Students can start over"): how many questions each student gets each time
  they play, picked at random from the Questions tab. Every Start Over brings a new mix, first the questions they didn't get the
  last time. So a student who writes down the answers and plays again gets different questions. Blank or 0 = every question, the
  way the game works now.
- The grade is still out of Points possible, and it counts only the questions in that try: 40 right out of 40 is full credit, and
  Full credit at works the same way (70% of 40 = 28 right). The best try is still the grade.
- Answering every question of the try finishes the game and turns it in, as before. Power-ups still come every 4 answers.
- The game page counts only the try's questions ("3 / 40", "40 questions remaining", "34 of 40 right").
- Live Results still has a column for every question in the Questions tab (Q1 to Q91). A question that isn't in a student's try
  stays blank there. Status says how far the try is, like "Try 2: 28 of 40 answered (best try 85%)", and Green, Red and Blank count
  only the try's questions.
- Question Summary has a new column, Times given: how many students' tries have that question. Green, Red, Blank and % green count
  only those students (a question that wasn't in a student's try doesn't count as blank).
- Self-Check > Check the Questions tab for problems tells you how it's set, like "Each try gets 40 of the 91 questions at random."
- Work students did before this update keeps its grade: a try from before counts the first questions in the Questions tab (as many
  as Questions per try), which are the questions the game had then. So add new questions BELOW the ones you have (never in between),
  and set Questions per try before students play the new questions. A student partway through an old try finishes those same
  questions; their next Start Over brings the new mix.
- To use it: paste BOTH new files (Code.gs and Index), then New version, then run Self-Check > Set up / repair sheets (it adds the row,
  set to 0). Then type the number in the row. (With the new Code.gs but the old Index, students who open the sheet's own link would
  see every question, and answers to questions outside their try wouldn't save.) Students who open the game through the class
  website (Class Pass) get the new page as soon as it is published.
- Your questions, settings, scores and leaderboard are not touched.
