class-list v2026.11.11

- Broken videos and links: your class website now checks its videos and web links every night. About once a week, when something new
  has stopped working, this sheet emails you the list (from your own account, to you), with how many replacements are ready to pick
  on the website's Site check page (Class Pass menu > Site check).
- Settings tab: a new row, "Email me when videos or links stop working" (checked). Uncheck it to stop the emails.
- Class List menu: "Email me about broken videos and links now" asks the website at once instead of waiting a day.
- This update asks for ONE new permission (to send you email), which only you can approve, so the Launchpad's Update now can't install it.
  To get it: open the Class List sheet, choose Class List > Update this sheet's code, reload the sheet, then choose
  Class List > Email me about broken videos and links now. Google asks you to allow it to send email as you: press Allow.
  Until you do, the hourly class list sync waits, so do it soon after updating.

Also from 2026.11.10f, if this sheet skipped it:
- Every error from Google now shows Google's own words too, and a new message tells apart the two different "Apps Script API is off"
  problems: the switch on your settings page (script.google.com/home/usersettings) and the Google Cloud project behind this sheet.

Also from 2026.11.10e, if this sheet skipped it:
- Fix: the sheet now also reads its web app's address from the Settings tab ("Web app (for the Launchpad)") when it hasn't remembered
  it, and remembers it. Before, a sheet could show the address there but send the site an empty one, so the Launchpad said the sheet
  "hasn't told the site its web app yet" and showed no Update now buttons. The next sync (Sync now, or within the hour) fixes it.
- A clear message when the sheet is missing its permission to change Apps Script projects ("Request had insufficient authentication
  scopes"): its appsscript.json must be the release's (it lists script.projects and script.deployments); paste it, Save, then run
  Class List > Set up and approve.

Also from 2026.11.10d, if this sheet skipped it:
- Class List > Set up sends the class list and the web app's address to the site by itself (when the Site key is already in).
- Clearer steps when the Launchpad needs an assignment sheet's Script ID (sheets on code older than 2026.11.10b, once).

Also from 2026.11.10c, if this sheet skipped it:
- A Nickname column in the Students tab (yellow, right after First name). A nickname takes the place of the student's first name on the
  website (Class Pass and the leaderboard). Every sync keeps it; clear the cell to go back to the first name.

Also from 2026.11.10b, if this sheet skipped it:
- The Class List sheet holds the class list for your class website's Class Pass sign-in and Leaderboard. Classes tab: tick Show; Shows as =
  the period number or a name. Added by hand tab: anyone else. Class List > Sync now sends it; it also syncs every hour when something changed.
- It is also the Assignment Launchpad's helper: Update now on a card updates that assignment sheet's code and student link; Undo puts it back.
