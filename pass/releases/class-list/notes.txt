class-list v2026.11.10c

- New: a Nickname column in the Students tab (yellow, right after First name). Type a nickname there and the website uses it instead of
  the student's first name (Class Pass's "Signed in as" and the leaderboard's names, like "Avi A."). It is the one column of the Students tab
  you type in: every sync rewrites the rest of the tab but keeps the nicknames, and a student who leaves a ticked class and comes back keeps
  theirs. Clear the cell to go back to the first name. A new or changed nickname goes to the site with the next sync (Sync now, or within the hour).
- To get it: on the Assignment Launchpad, Class List sheet box > Update now (or in this sheet: Class List > Update this sheet's code).
  The Nickname column shows up at the next sync. No new permission is needed.

Also from 2026.11.10b, if this sheet skipped it:
- The Class List sheet holds the class list for your class website's Class Pass sign-in and Leaderboard, so you no longer paste the roster
  on the Leaderboard page. Classes tab: tick Show for the classes on the site; Shows as = the period number (4) or a name (Test).
- Added by hand tab: anyone else, or a fix to a name or period. Class List > Sync now sends the list; it also syncs every hour when something
  changed, and asks first before taking more than half the students off the site.
- It is also the Assignment Launchpad's helper: Update now on a card updates that assignment sheet's code and student link; Undo puts it back.
